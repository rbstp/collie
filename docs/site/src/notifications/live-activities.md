# Live Activities

Follow an agent to keep it on the Lock Screen and in the Dynamic Island. Following is off by default.

1. Open the agent screen's menu, or long-press the agent, and choose **Follow on Lock Screen**.
2. You can follow up to 5 agents at once. Each shows its status and how long it has been in it.

When a followed Claude Code agent blocks on a permission prompt, the activity shows the command with **Approve** and **Deny** buttons. Other prompts, and Codex or Copilot CLI agents, arrive as a regular notification instead.

Only your phone can read what a Live Activity shows, including names, status and pending commands: `collied` encrypts all of it. Apple sees generic alert text, opaque IDs, priority, timing, size and when an activity starts and ends. Before the first unlock after a restart, or if the phone cannot decrypt an update, the activity shows a neutral state without approval controls.
