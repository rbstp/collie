# Live Activities

Follow an agent to keep it on the Lock Screen and in the Dynamic Island. Following is off by default.

To follow an agent, open the agent screen's menu, or long-press the agent, and choose **Follow on Lock Screen**. You can follow up to 5 agents at once; each shows its status and for how long.

When a followed Claude Code agent blocks on a permission prompt, the activity shows the command with **Approve** and **Deny** buttons, which need the iPhone unlocked. Other prompts, and Codex or Copilot CLI agents, arrive as a regular notification instead.

Only your phone can read what a Live Activity shows, including names, status and pending commands: all of it is encrypted. Apple sees generic alert text, opaque IDs, priority, timing, size and each activity's lifecycle. Before the first unlock after a restart, or if the phone cannot decrypt an update, the activity shows a neutral state without approval controls.
