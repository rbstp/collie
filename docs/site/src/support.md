# Support

collie is an open source project maintained by Richard Boisvert. You get help through GitHub issues.

## Get help

1. Check [Troubleshooting](troubleshooting.md).
2. Search the [existing issues](https://github.com/rbstp/collie/issues).
3. [Open an issue](https://github.com/rbstp/collie/issues/new) with:
   - what you expected and what happened;
   - the app and iOS versions;
   - the output of `collied doctor` and `collied status`, without private details such as machine names and paths.

Never paste APNs keys, auth keys, pairing QR codes or invite links in an issue.

## Report a security problem

Do not describe a vulnerability in a public issue. Open an issue that only asks for a private contact, and the maintainer will follow up.

## Open source licenses

**Acknowledgements**, in Settings or at the bottom of the Welcome screen, lists every open source component in the app with its license. The `collied` downloads list theirs in `THIRD_PARTY_NOTICES`.

## Privacy

The [privacy policy](privacy.md) describes what collie collects and sends.
