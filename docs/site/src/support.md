# Support

collie is an open source project maintained by Richard Boisvert. You get help through GitHub issues.

## Get help

1. Check [Troubleshooting](troubleshooting.md), which starts every symptom from `collied doctor`.
2. Search the [existing issues](https://github.com/rbstp/collie/issues).
3. [Open an issue](https://github.com/rbstp/collie/issues/new) with:
   - what you expected and what happened;
   - the app version and your iOS version;
   - the output of `collied doctor` and `collied status`, after removing anything private such as machine names or paths.

Never paste APNs keys, auth keys, pairing QR codes or invite links in an issue.

## Report a security problem

Do not put the details of a vulnerability in a public issue. Open an issue that only asks for a private contact, and the maintainer will follow up.

## Open source licenses

Acknowledgements, in Settings or at the bottom of the Welcome screen, lists every open source component built into the app; tap one to read its license. The collied downloads list theirs in `THIRD_PARTY_NOTICES`.

## Privacy

What collie collects and sends is described in the [privacy policy](privacy.md).
