# Key strip and gestures

## The key strip

The key strip sends the keys an iPhone keyboard lacks, such as Escape, arrows and Control combinations. The **Keys** button, right of the paperclip, shows or hides it. The strip starts hidden, and your choice applies to every session on this phone.

The first row is:

```text
⇧  ⌃  E  ←  ↑  ↓  →  ⇥  ⌫  ⏎
```

`E` sends Escape. Tap ⇧ or ⌃, then a key, to send the two together, such as ⇧⇥ or ⌃⏎. With ⌃ selected, a letter typed on the keyboard sends Control and that letter (A, B, C, E, K, L, U or W). A modifier applies to the next key only; tap it again to clear it.

The second row scrolls. It offers `⇧⇥ ⌃⏎ ⇧← ^C` in one tap, then your key shortcuts, then **+** to add one. Keys that a session cannot use are turned off.

## Key shortcuts

Add your own buttons in **Settings > Prompt > Key shortcuts**, or with **+** on the strip:

- a key or a two-key combination, such as Shift+Tab;
- text, such as `/effort high`.

A shortcut can apply to every session or to one kind: Claude Code, Codex, Copilot CLI or Terminal. A text shortcut is sent at once and leaves your draft alone. Claude Code refuses it while its input box holds unsent text, while Codex and Copilot CLI add it after any text there. A text shortcut runs as a command only in a terminal, and only when its kind is Terminal.

Swipe to delete a shortcut, and use **Edit** to reorder. Shortcuts stay on this phone.

## Gestures

Choose what each gesture does in **Settings > Terminal > Gestures**:

| Gesture | Action |
|---|---|
| Double-tap | Paste into the prompt field |
| Pinch | Change the font size |
| Swipe sideways | Switch agents (while lines wrap) |
| Triple-tap | Send Esc (off by default) |
