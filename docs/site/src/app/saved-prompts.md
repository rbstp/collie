# Saved prompts

Saved prompts let you name a prompt once and reuse it.

- **Add** one in **Settings > Prompt > Saved prompts**, or from the paperclip menu in an agent or in New task.
- **Use** one from the paperclip menu: choose **Saved prompts**, then tap it. It fills an empty composer or is appended to your draft. Edit it, then send.
- **Edit or delete** one by swiping it.

Saved prompts stay on this phone and work with every project and machine.
