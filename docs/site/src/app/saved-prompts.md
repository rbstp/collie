# Saved prompts

Name a prompt once and reuse it with every project and machine.

- **Add** one in **Settings > Prompt > Saved prompts**, or from the paperclip menu in an agent or in New task.
- **Use** one from the paperclip menu: choose **Saved prompts**, then tap it. It fills an empty composer or joins the end of your draft, without sending.
- **Edit or delete** one by swiping it.

Saved prompts stay on this phone.
