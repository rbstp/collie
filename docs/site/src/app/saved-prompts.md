# Saved prompts

Name a prompt once and reuse it with every project and machine.

- **Add** one in **Settings > Prompt > Saved prompts**, or from the paperclip menu in an agent or in New task.
- **Use** one from the paperclip menu: choose **Saved prompts**, then tap it. It fills an empty composer or joins the end of your draft, without sending. In [Terminal](chat-terminal.md#terminal), it is typed into the agent instead, unless the agent is waiting for your answer: then it joins the draft in Chat.
- **Edit or delete** one by swiping it.

Saved prompts stay on this phone.
