# ADR-0006: The desktop bars speak collied's control socket and confirm pairings on the machine

- Status: accepted
- Date: 2026-11-20 (recorded from the comments of `Mac/`, `Linux/`, `scripts/desktop/install.sh` and the justfile)

## Context

CollieBar (macOS) and CollieTray (Linux, Omarchy) show collied's state, start and stop it, and run a pairing whose confirmation must happen on the machine. AGENTS.md keeps the two aligned.

## Decision

The wire:

- Both speak collied's control socket (`crates/collied/src/control.rs`): one JSON object per line, a new connection per request. collied refuses unknown keys, so the bars send exact lines, which their tests pin. The line limit is collied's `MAX_LINE` (64 KiB), and the terminal key wording follows `Candidate::terminal_key_change`.
- The socket is 0600 in collied's 0700 data folder, and collied checks the peer's uid: only the user's own processes reach it. CollieBar reads `HOME` as collied does (`config::home_dir`), so a test collied with its own `HOME` works.
- The status is pushed by collied over one held connection; the only polling is a failing connect every retry interval while collied is off. A Quickshell `Socket` never connects again after a failed attempt, so CollieTray makes a new one for each attempt.

Pairing:

- The invite carries the one-time code. It is never logged, shown as text, copied or kept: only its QR image lives in the window's or the bar's state. CollieTray draws the QR natively, one rectangle per module with the quiet zone as padding, so the code never touches a file, and hands the URI to `qrencode` on stdin only, since argv shows in `ps` (`qrencode -t ASCII` draws a module as `##` or two spaces, read as rows of 1 and 0).
- Closing the pairing window, or a bar going away with its screen, closes the connection; collied takes the closed connection as a cancel, or as Don't Pair, as it takes Ctrl-C.
- Pair has no default button and goes live only a second after the candidate shows, so Return or a click meant for something else cannot approve a phone.
- Strings from the phone go through `printable`, like `collied::printable` (`char::escape_debug`): control, format (bidi included), separator, combining, default-ignorable and non-ASCII space characters are shown escaped, never interpreted. CollieTray's `Printable.js` is generated by `Linux/Tests/gen-printable.mjs`, since Quickshell's JS has no `\p{}` classes.

Start, stop and install:

- After a start the bars show "starting" for up to 90 s: the tailnet can take up to a minute to come up. "already stopped" from `collied stop` means a collied launchd does not manage, and is shown as the error. CollieTray's Quit stops collied and takes the icon off the bar; the shell stays up.
- CollieTray reads the systemd unit `collied service install` writes: it undoes its quoting (`\"`, `\\`, `%%`, and the `$$` of arguments, while the executable keeps its `$`) and reads the executable and the pinned `XDG_DATA_HOME` that `collied stop` and `start` use. Its test fixture is what `crates/collied/src/service/systemd.rs` writes. `scripts/desktop/install.sh` rewrites `ExecStart` with percent signs doubled and sed's specials escaped: systemd does not expand dollars in the executable path, but percent still expands specifiers.
- `just collied-install` copies to a fresh inode and renames it over the old binary: on macOS rewriting a signed binary in place can get the running copy killed, and on Linux the running daemon keeps its own copy until it restarts. `just mac-install` builds a fresh copy beside the old app and swaps it in, so the path stays stable for the login item. `just tray-install` copies into a dot folder, which the shell's watcher ignores, so plugins reload once, at the swap; an update restarts the shell, whose hot reload can keep a changed widget's old component cached; and the install waits while the shell answers "not ready", until it has found the plugin ("on the bar already" counts as done).
- The tray icon is an SVG mask filled with the bar's colour, so a tint follows the theme.

Tests:

- CollieBar's tests run a scripted control socket in a temporary folder and never touch the real one. Lines are collected by one long-lived reader, so a timed-out wait does not cancel the stream, which would close the connection.
- CollieTray's service test times from the first running state, since collied starts after the widget.

## Consequences

- A field collied adds to a reply the bars read is decoded by both; a request field the bars send must be one collied accepts, or every request fails.
- A change to one bar's pairing or start behavior is made to both.
